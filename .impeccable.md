## Design Context

### Users
Frequent users of a native desktop text editor, including developers customizing code appearance by language and file extension.

### Brand Personality
Quiet, precise, focused. Keep the editor comfortable for sustained work.

### Aesthetic Direction
Follow the compact native Settings interface and the normative design system in `docs/specs/21-themes-and-design-system.md`. Support light and dark themes. Avoid decorative dashboards, large cards and excessive spacing.

### Design Principles
- Make appearance changes concrete through the real editor preview.
- Keep drafts local until Save, with clear recovery from errors.
- Expose inheritance and explicit preference overrides.
- Preserve keyboard access, readable contrast and localization.
