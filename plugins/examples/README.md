# Example plugins

Sample Lua plugins for Notoir (docs/specs/30-lua-plugins.md). They are also the fixtures of
`apps/notoir/tests/plugin_examples.rs`. Install one with **Plugins › Install Plugin from
Folder…** and pick its folder.

| Plugin | Shows |
|---|---|
| `word-count` | a command with a keybinding and menu entries, a status item, a plugin setting, `require`, translations |
| `todo-highlighter` | a declarative panel, an outline provider, a language with a `.sublime-syntax` grammar |
| `markdown-table-formatter` | a formatter used by Format Document |
